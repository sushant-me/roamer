# Posting the AstroLens story on LinkedIn

## Option A — document/carousel post (recommended)
1. LinkedIn → **Start a post** → click the **+** → **Add a document**.
2. Upload `AstroLens_LinkedIn_carousel.pdf`.
3. Title: **“Where on Earth should we test Moon and Mars hardware?”**
4. Paste the caption from `linkedin_post.txt`.
5. Tag **NASA Space Apps** and, if you like, your local event page.
6. Post. (Native documents get more dwell time than link posts.)

## Option B — single image post
Use `AstroLens_LinkedIn_cover.png` as the image, same caption.

## Alt text (accessibility)
Cover: “AstroLens cover slide: Where on Earth should we test Moon and Mars hardware? 36 hours, one hard question, 34 sites, 500 m grid, 7 features, NASA Space Apps 2026 Galactic Problem Solver certificate.”

## Notes
- The first 2 lines are the hook — keep them exactly as written.
- Links go at the bottom; LinkedIn can shorten previews, so the plain URL is intentional.
- Replace “Last weekend” if you post later.
- The certificate is a **participation certificate** (“Galactic Problem Solver”), not an award — keep the wording as written.
- Files: carousel PDF, cover PNG, caption text, this guide.
